# Рядом — P2P-мессенджер по Bluetooth

Простой мессенджер для двух телефонов, которые находятся рядом. Работает напрямую
через Bluetooth Classic (RFCOMM), без интернета, сервера, аккаунта и регистрации.

## Проблема

Обычные мессенджеры требуют сеть: мобильный интернет или Wi‑Fi, сервер, учётную
запись, подтверждение номера. При этом связь часто нужна именно там, где сети нет
или она ненадёжна: в походе, в метро, в самолёте, на фестивале, в подвале,
за городом, при перебоях связи. Возникает парадокс: два телефона в метре друг
от друга не могут обменяться парой фраз без облака.

## Решение

Приложение поднимает RFCOMM-сервер на каждом устройстве и позволяет одному
подключиться к другому. Дальше это обычный чат с сообщениями в одну строку.
Никаких «наворотов»: один экран, один собеседник, одно поле ввода.

## Как запустить

1. Установить `P2P-Messenger-debug.apk` на два телефона (Android 8.0 / API 26+).
2. Включить Bluetooth и выдать разрешение «Устройства рядом».
3. На одном телефоне нажать «Показать меня», на другом — «Найти рядом».
4. Выбрать устройство из списка и писать сообщения.

При первом подключении система может показать диалог сопряжения — это штатный
шаг Bluetooth.

## Технические детали

| | |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3, анимированные градиенты |
| Транспорт | Bluetooth Classic RFCOMM, `BluetoothServerSocket` / `BluetoothSocket` |
| Протокол | UTF‑8 строки с разделителем `\n` |
| Архитектура | `ViewModel` + `StateFlow`, Bluetooth-слой в `ChatLink` |
| Настройки | `SharedPreferences` + `StateFlow`: тема (системная/светлая/тёмная), язык (RU/EN) |
| minSdk / targetSdk | 26 / 37 |
| Сборка | Gradle 9.5 (AGP), Kotlin 2.2.10 |

Тема и язык переключаются в приложении через иконку шестерёнки. Язык меняется
без перезапуска процесса (`createConfigurationContext` + `recreate()`),
все строки — в `values/strings.xml` и `values-en/strings.xml`.

Тёмный фон использует эффект «живых облаков» в стиле Gemini: четыре больших
полупрозрачных цветовых пятна движутся по разным орбитам. Анимация намеренно
вынесена в **draw-фазу** (`Modifier.drawBehind`), а не в composition: чтение
`State<Float>` в `@Composable` вызывает рекомпозицию всего дерева 60 раз в секунду
и может привести к ANR.

Ключевые файлы:

- `app/src/main/java/com/example/p2pmessenger/bluetooth/ChatLink.kt` — сокеты,
  поиск устройств, разрешения, переподключение.
- `app/src/main/java/com/example/p2pmessenger/ChatViewModel.kt` — состояние чата.
- `app/src/main/java/com/example/p2pmessenger/ui/ChatScreen.kt` — экран, шторки и превью.
- `app/src/main/java/com/example/p2pmessenger/ui/theme/Gradient.kt` — «живые» градиенты.
- `app/src/main/java/com/example/p2pmessenger/settings/` — тема, язык, локализация.
- `app/src/main/res/values-en/strings.xml` — английский перевод.

## Ограничения

- Один собеседник на соединение (осознанно: «без наворотов»).
- История сообщений живёт в памяти процесса и не сохраняется после закрытия.
- Нет шифрования: RFCOMM-канал защищён только сопряжением Bluetooth.
  Не предназначено для конфиденциальных данных.
- Дальность — типичная для Bluetooth Classic (~10 м без препятствий).

## Сборка из исходников
